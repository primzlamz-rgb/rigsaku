Pustaka NAM & IR

GP-100 menyimpan 20 IR pengguna dan capture NAM (SnapTone). Pengiriman ke pedal saat ini lewat Valeton Suite di PC: unduh file dari sini, lalu impor di Suite.

Uji Sinkron Pedal

kunci untuk edit knob dari HP
  1. Pastikan GP-100 tersambung (tab Kontrol).
  2. Tekan Mulai uji.
  3. Di pedal: buka modul AMP, lalu putar satu knob (mis. Gain) pelan dari kiri ke kanan. Setelah itu ganti patch sekali.
  4. Tekan Selesai, lalu kirim hasilnya ke Claude.

Lab ini untuk membongkar protokol editor penuh. Biarkan monitor jalan, lalu putar knob, ganti patch, atau injak footswitch di pedal. Kalau ada pesan SysEx GP-100 yang masuk (ditandai), salin log dan kirim ke Claude.

Tentang

Rig Saku v1.0 · kontrol via MIDI CC standar GP-100 · rekaman WAV lewat USB audio. Bukan aplikasi resmi Valeton. Editor parameter penuh menyusul setelah protokol SysEx GP-100 terbongkar (lihat tab Lab).

Knob

Geser knob ke atas/bawah, atau pakai tombol − / +. Ketuk dua kali untuk nilai bawaan.

Nilai knob belum bisa dikirim otomatisProtokol penyetelan GP-100 belum terbuka, jadi setel angka ini di pedal (pakai "Panduan setel"). Cara cepat untuk 1 knob: tugaskan pedal EXP patch ini ke parameter itu di pedal, lalu geser slider Expression di tab Kontrol.
